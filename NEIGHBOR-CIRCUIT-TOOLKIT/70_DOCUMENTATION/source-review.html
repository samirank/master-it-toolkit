SOURCE REVIEW · SEPTEMBER 9, 2026

Know where your tools come from.

What was checked

Official vendor and project pages were checked on September 9, 2026. The local audit records HTTP results, redirect targets and page titles. Follow-up web retrieval was used for several sites that block direct checks. Reachability establishes a source link, not a software security review, commercial-use approval or a verified latest version.

Version numbers are intentionally absent where a reliable check was unavailable. The online metadata updater can check supported GitHub releases; other editions and installers require manual version review.

Catalog decisions

  • 221 useful records include software, Windows/Linux built-in commands, firmware/driver libraries and 8 supplied local scripts/reference assets. No downloaded software is bundled.
  • Revo Portable, EaseUS and other commercial entries have licensing warnings and dedicated licensed-software folders. The Revo page documents per-user portable licensing. Free personal editions must not be assumed valid for client work.
  • Geek uses geekuninstaller.com; HiBit uses hibitsoft.ir. Similar-looking .org/.io domains are not used. HiBit is an optional uninstaller only: its registry cleaner is not recommended.
  • OptimizerNXT is a specialty YAML-based tool with potentially broad effects; it is P3/HIGH RISK. No bundled presets execute it.
  • O&O currently brands its page ShutUp10 and offers free/Premium choices. The familiar ShutUp10++ name is retained as a search alias.
  • UniGetUI now resolves to Devolutions/UniGetUI. Project links have been updated.
  • HDDScan remains optional P4: the publisher still offers 4.1, but recent development could not be established. Victoria is omitted because a sufficiently reliable current publisher/build provenance was not established during this build. No third-party repack was substituted.
  • Kaspersky's official rescue download is listed as a specialty option. Confirm current definitions, regional availability and organization policy. No guarantee of current offline definitions is implied.
  • Western Digital support is a model-selection entry, not a promise that an old Dashboard utility still supports all WD/SanDisk products. Crucial's site rejected automated retrieval; that entry remains explicitly manual-check.
  • iperf3 uses official ESnet sources and is labeled Linux: no unofficial Windows binary has been linked. Native Windows networking commands are included separately.
  • Firefox, LibreOffice and VLC Portable point to their explicitly named PortableApps.com package publisher; upstream apps and portable packaging have distinct provenance.
  • FreeFileSync standard deployment is installed; portable packaging depends on edition. Installer presence is not portable capability.
  • The entire Sysinternals Suite is cataloged; highlighted component entries are grouped by their shared folder. Inventory markers do not prove every member is present.
  • No authentication bypass, pirated software, offensive malware, speculative registry cleanup or automatic unattended access is included.
